# Copy as Markdown

**Right-click any element → copy as clean Markdown.** Preserves structure, links, images, code blocks, tables. Works on any page.

## Install

**Chrome/Edge/Brave:** Load as unpacked extension in Developer Mode, or install from [Chrome Web Store](https://chromewebstore.google.com/detail/copy-as-markdown) (pending).

## Usage

1. Right-click any element on any page
2. Select **Copy as Markdown**
3. Paste anywhere — clean Markdown with structure preserved

### Keyboard Shortcut

`Alt+M` — copy current selection as Markdown

## What Gets Preserved

| Element | Markdown |
|---------|----------|
| Headings (h1-h6) | `#` `#` `###` etc. |
| Paragraphs | plain text |
| Links | `[text](url)` |
| Images | `![alt](src)` |
| Bold/Italic | `**bold**` `*italic*` |
| Code | `` `code` `` / code blocks |
| Lists | `- item` / `1. item` |
| Blockquotes | `> quote` |
| Tables | pipe tables |
| Block elements | semantic structure |

## Privacy

- **No tracking, no analytics, no network requests**
- Only accesses the current tab when you click the menu
- No data leaves your browser

## Install (Developer Mode)

1. Clone or download this repo
2. Open `chrome://extensions` (or `edge://extensions`)
3. Enable **Developer mode** (top right)
4. Click **Load unpacked** → select this folder
5. Right-click any page → **Copy as Markdown**
